# Raw Data

This folder holds notes, research, references, exports, legacy documents, and temporary information that may be relevant to the project or may later be shaped into a draft specification.

Raw data does not need specification naming. It may be incomplete, mixed, uncertain, or contradictory.

Nothing in this folder is an accepted requirement or source of truth. To become a requirement, the relevant information must first be written as a compliant spec in `../specs/drafts/`, explicitly approved by the user, and then moved to `../specs/accepted/`.
