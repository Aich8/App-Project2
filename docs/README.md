# Documentation

This folder contains project documentation outside the application code.

## Structure

- `specs/README.md`: specification types, naming rules, lifecycle, and accepted-spec index.
- `specs/accepted/`: approved `GlobalSpec`, `FeatureSpec`, and `TechnicalSpec` files.
- `specs/drafts/`: new or revised specifications waiting for explicit user approval.
- `raw-data/`: notes, references, exports, legacy documents, and temporary project information.
- `plans/active/`: current implementation plans.

Application code lives in `../website/`.
